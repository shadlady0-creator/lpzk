# ЛПЗК — сайт Либеральной партии зайцев и кроликов

> «Плодимся быстрее, чем Дума принимает законы.»

Статичный сайт партии: манифест, принципы, программа и цели, полный Устав (с поиском), состав руководства и генератор заявления о вступлении.

Без сборки и сервера — только `index.html`, `styles.css`, `app.js` и `team.js`.

## Как посмотреть локально

Просто откройте `index.html` в браузере.

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub (например, `lpzk-site`) и отправьте туда код:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/lpzk-site.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/lpzk-site/`.

## Как обновить состав партии

Откройте `team.js` и впишите имя в поле `name` нужной должности (номер паспорта — в `passport`, по желанию). Пустое имя показывается на сайте как «Вакантно».

## Заявление о вступлении

Форма на сайте собирает заявление по утверждённому шаблону прямо в браузере — данные никуда не отправляются. Готовый текст копируется одной кнопкой.
